# SDK

The runtime and recompiler this port is built with: an iOS-capable version of the ReXGlue SDK
(Xbox 360 kernel, audio, input and Xenos GPU emulation on Vulkan through MoltenVK, and the
PowerPC-to-C++ code generator). License terms are in [LICENSE](LICENSE).

Build it once for the Mac (host tools and the macOS test runtime) and once for iOS; see the
repository's main README.
